Kenapa center terpisah dari property of text dikarenakan pada dasarkan  di flutter terdapat prinsip single responsibility yang berarti setiap komponen atau class hanya memiliki satu tugas utama. Center digunakan untuk mengatur tata layout serta posisi child sedangkan text bertanggung jawab untuk mengatur font, ukuran kata, atau ketebalan huruf. Text tidak menentukan atau mempedulikan tempat dimana ia disimpan tetapi center lah yang menentukan dimana letak childnya di layar. Dengan memisahkan kedua job atau tugas tersebut maka efisiensi kodingan dapat lebih optimal dengan hanya berfokus pada tugas utamanya tanpa perlu melakukan tugas di luar tanggung jawabnya.
